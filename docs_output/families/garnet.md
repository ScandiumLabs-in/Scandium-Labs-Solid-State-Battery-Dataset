# Garnet (LLZO-type)

**Family:** `garnet`

**Records:** 68
**Records with conductivity label:** 28

## Description

Garnet-structured Li-ion conductors, typified by Li7La3Zr2O12 (LLZO) and its doped variants. Good chemical stability against Li metal.
