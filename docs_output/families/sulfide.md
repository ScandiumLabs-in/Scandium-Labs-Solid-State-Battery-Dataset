# Sulfide (Thio-LISICON)

**Family:** `sulfide`

**Records:** 804

## Description

Li-ion conductors based on sulfide frameworks, including thio-LISICONs (Li10GeP2S12). Typically the highest room-temperature conductivities (1e-3 to 1e-1 S/cm).
