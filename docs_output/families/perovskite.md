# Perovskite (LLTO-type)

**Family:** `perovskite`

**Records:** 1
**Records with conductivity label:** 1

## Description

Li-stuffed perovskite oxides based on Li3xLa2/3-xTiO3 (LLTO). High bulk conductivity but significant grain-boundary resistance.
